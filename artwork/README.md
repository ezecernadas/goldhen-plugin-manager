# Artwork

`icon0.svg` is the source of `sce_sys/icon0.png` (512x512) and `sce_sys/save_data.png` (228x128).
It is generated by `gen_icon.py` (writes `v2b_tilt.svg`); render with Inkscape and flatten with ImageMagick:

```
python3 gen_icon.py
inkscape v2b_tilt.svg -w 512 -h 512 -o icon0.png
convert icon0.png -background "#002887" -alpha remove -alpha off PNG24:../sce_sys/icon0.png
convert -size 228x128 xc:"#002887" \( icon0.png -resize x112 \) -gravity center -composite PNG24:../sce_sys/save_data.png
```

Style follows the PS4 Cheats Manager icon (flat shapes, navy outlines, background `#002887`).
